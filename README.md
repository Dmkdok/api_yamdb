## YaMDb API

**Описание проекта:**

YaMDb - это API для сбора и хранения отзывов пользователей о произведениях искусства. 

**Цель проекта:**

Создать API, позволяющий пользователям оставлять отзывы о книгах, фильмах, музыке и других произведениях, а также просматривать рейтинги и комментарии к ним.

**Возможности API:**

* **Аутентификация и авторизация:** API использует JWT-токены для аутентификации пользователей.
* **Управление пользователями:**
    * Регистрация пользователей с подтверждением по email.
    * Авторизация пользователей с помощью username и password.
    * Изменение профиля пользователя.
* **Работа с произведениями:**
    * Получение списка произведений по категориям.
    * Поиск произведений по названию.
    * Получение подробной информации о произведении.
    * Добавление, редактирование и удаление произведений (только администраторы).
* **Работа с категориями:**
    * Получение списка категорий.
    * Добавление, редактирование и удаление категорий (только администраторы).
* **Работа с жанрами:**
    * Получение списка жанров.
    * Добавление, редактирование и удаление жанров (только администраторы).
* **Работа с отзывами:**
    * Добавление, редактирование и удаление отзывов (только авторизованные пользователи).
    * Поиск отзывов по произведению.
    * Установка рейтинга произведения.
* **Работа с комментариями:**
    * Добавление, редактирование и удаление комментариев (только авторизованные пользователи).
    * Получение списка комментариев к отзыву.

**Настройка и запуск:**

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/Dmkdok/api_yamdb.git
    ```

2.  **Создайте и активируйте виртуальное окружение:**

    ```bash
    python -m venv venv
    source venv/bin/activate
    ```

3.  **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

4.  **Настройте базу данных:**

    Измените настройки базы данных в файле `settings.py`.

5.  **Запустите миграции:**

    ```bash
    python manage.py makemigrations
    python manage.py migrate
    ```

6.  **Запустите сервер разработки:**

    ```bash
    python manage.py runserver
    ```

**Документация:**

Полная документация по API YaMDb доступна по адресу: [http://127.0.0.1:8000/redoc/](http://127.0.0.1:8000/redoc/).

**Данные:**

Данные для инициализации базы данных находятся в директории `/api_yamdb/static/data`.
